# Held Judge Text

A tiny deterministic Node program for the make.fun bounty
`make-the-ai-judge-feel-held-20261122-1600`. When run, it writes a single short
piece of prose to `/output/entry.txt` — a quiet scene of a body resting in a
length of cloth strung between two old trees, held from below and swaying
almost imperceptibly, with nothing asked of the reader and nothing to prove.
The text is a fixed constant inside `main.ts`; every run produces the exact
same bytes, with no network access, no randomness, and no external input.
